Wall code legend

Code = room + wall direction + optional span number + face. I marks the side facing that room or covered space; E marks the outer face. Shared partitions have one code for each room-facing side. -X labels the wall extension above the second-floor ceiling; for example, R1-W2I-X is the upper extension of R1-W2I.
